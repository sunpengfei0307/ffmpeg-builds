# delogo_cuda

在 CUDA 帧上去掉一块台标。算法与 CPU `delogo` 相同（用区域边缘像素做加权插值），另外可以用 `blur` 把修补区域再模糊一档。

## 变更记录


| 日期         | 说明                                                      |
| ---------- | ------------------------------------------------------- |

## 设计方案（核心功能）

1. 输入必须是 `AV_PIX_FMT_CUDA`。软件格式与 `scale_cuda` 相同，至少覆盖 `yuv420p` / `nv12` / `p010`
2. 先按 `delogo` 的边缘插值填掉台标，再按 `blur` 半径对修补区域做盒式模糊
3. `blur=0` 就是原来的插值（更清晰）。半径越大，修补块越糊
4. `w<=0` 或 `h<=0` 时直接透传，方便先挂上滤镜再用命令打开
5. `x/y/w/h/show/blur` 带运行时标志，进程 `-zmq` 可直接改


| 文件                  | 职责            |
| ------------------- | ------------- |
| `vf_delogo_cuda.c`  | 选项、区域裁剪、按平面调度 |
| `vf_delogo_cuda.cu` | 插值、盒式模糊       |


构建：`CONFIG_DELOGO_CUDA_FILTER`（依赖 CUDA 与 GPL）。

## 参数说明


| 选项     | 默认  | 常用取值               | 作用                                   |
| ------ | --- | ------------------ | ------------------------------------ |
| `x`    | `0` | 台标左上角              | 区域左，像素                               |
| `y`    | `0` | 台标左上角              | 区域上，像素                               |
| `w`    | `0` | 台标宽                | `0` 表示不处理                            |
| `h`    | `0` | 台标高                | `0` 表示不处理                            |
| `show` | `0` | 调位置时设 `1`          | 画出处理框（与 CPU `delogo` 一样写成 0，YUV 上偏绿） |
| `blur` | `0` | `0` 清晰，`4`~`16` 更糊 | 修补区域盒式模糊半径，最大 `32`                   |


坐标会自动夹进画面。内部仍保留 `delogo` 的 1 像素 `band` 羽化，不另暴露。

支持的软件格式：`yuv420p` `yuv422p` `yuv444p` `yuv420p10` `yuv422p10` `yuv444p10` `yuv444p16` `nv12` `nv16` `p010` `p210` `p016` `p216`，以及 `0rgb` / `0bgr` / `rgb32` / `bgr32`。

## 用法示例

```text
hwupload_cuda,delogo_cuda=x=1600:y=40:w=280:h=80:blur=8
```

调位置时先看框：

```text
delogo_cuda=x=1600:y=40:w=280:h=80:show=1
```

运行时（进程 `-zmq`，目标名 `delogo_cuda`）：

```text
delogo_cuda x 1620
delogo_cuda blur 16
delogo_cuda show 0
```



## 注意事项

- 必须接在 `hwupload_cuda` 或其它 CUDA 滤镜之后
- `blur` 只糊修补块内部，不改画面其余部分
- `show=1` 时黑边不参与模糊，框保持可见
